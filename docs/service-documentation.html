📧 Notification Service

Sends HTML welcome emails to newly onboarded tenant admins via SMTP. Final step of the onboarding saga.

Port: 8095 MySQL: edusphere_notification_db SMTP / JavaMail Thymeleaf Templates
Overview

The Notification Service is the final step of the tenant onboarding saga. It sends a rich HTML welcome email to the newly onboarded tenant admin using SMTP (Gmail) via Thymeleaf email templates.

Key responsibilities:

  • Listen for NOTIFICATION_REQUESTED Kafka events and send HTML welcome emails
  • Render emails using Thymeleaf templates with institution name, subdomain, and login URL
  • Log every notification attempt (success or failure) to the notification_logs table
  • Important: A notification failure does not roll back the saga — onboarding is still marked COMPLETED
  • Stores notification records in MySQL database edusphere_notification_db (port 8095)

Gmail SMTP Setup
⚠️ Do not use your regular Gmail password. You must generate an App Password.

  1. Enable 2-Factor Authentication on the Gmail account
  2. Go to: Google Account → Security → App Passwords
  3. Create an app password for "Mail"
  4. Use that 16-character app password in MAIL_PASSWORD
